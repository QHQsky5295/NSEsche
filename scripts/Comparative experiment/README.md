# Academic Visualization for AAAI Conference

This directory contains scripts for generating publication-quality charts for serverless scheduling algorithms comparison.

## Features

- **Bar Charts**: Four metrics comparison (latency, cost, throughput, cost-performance ratio)
- **Stacked Bar Chart**: Latency breakdown (cold start, wait time, execution time)
- **Radar Chart**: Throughput comparison across different load types
- **Academic Styling**: Times New Roman font, colorblind-friendly palette, AAAI-compliant formatting

## Algorithm Mapping

| Internal Name | Display Name |
|---------------|-------------|
| sche_nash | NSESche (Proposed) |
| sche_orion | Orion |
| sche_jiagu | Jiagu |
| sche_Hiku | Hiku |
| sche_OCS | OCS |
| sche_FaaSRank | FaasRank |
| greedy | Greedy |
| random | Random |
| hash | Hash |
| load_least | Load Balance |

## Load Types

- `rflow` → Low Load
- `rfmiddle` → Middle Load  
- `rfhigh` → High Load

## Usage

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the visualization script:
   ```bash
   python academic_visualization.py
   ```

3. Generated files:
   - `performance_comparison.pdf/png` - Bar charts for all metrics
   - `throughput_radar.pdf/png` - Radar chart for throughput

## Output Format

- **PDF**: Vector format for publication
- **PNG**: High-resolution raster format (300 DPI)
- **Font**: Times New Roman (academic standard)
- **Layout**: Optimized for AAAI double-column format

## Data Source

The script reads experimental data from `../cache/*.json` files generated by the simulation framework.

## Customization

To modify colors, fonts, or chart types, edit the configuration variables at the top of `academic_visualization.py`.
